# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Use the repository host's private vulnerability-reporting channel; if private reporting is unavailable, contact the maintainers privately through the repository host. Include the affected component, impact, and concise reproduction details. Do not include real contract text, personal data, or live credentials.

## Supported scope

Reports are welcome for the current source in `lib/`, `artifacts/api-server/`, `artifacts/clause-compass/`, and the repository's build and deployment configuration. Test only deployments and data you own or have explicit permission to assess. Third-party services, provider-side incidents, social engineering, denial-of-service, and unsupported dependencies or deployments are outside this project's scope.

See the [threat model](docs/THREAT_MODEL.md) for documented boundaries and mitigations.
